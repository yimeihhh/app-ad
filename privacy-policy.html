「增幅态势」隐私政策

开发者：一枚硬币工作室
生效日期：2026年8月28日

一、引言

《增幅态势》（以下简称"本游戏"）由一枚硬币工作室（以下简称"我们"）开发并运营。我们非常重视您的个人信息和隐私保护。本隐私政策旨在说明本游戏如何收集、使用、存储和共享您的个人信息，以及您享有的相关权利。

请您在使用本游戏前仔细阅读并充分理解本政策。您开始使用本游戏，即表示您已同意本政策的内容。如您不同意，请停止使用本游戏。

二、我们收集哪些信息

本游戏接入 TapTap 开放平台（登录与实名认证/防沉迷服务）及 Unity Ads（激励视频广告服务），可能收集以下信息：

  • 设备信息：设备型号、操作系统版本、屏幕分辨率、设备标识符（包括广告标识符 IDFA/OAID）等，用于广告投放与问题排查。
  • 登录信息：您通过 TapTap 账号登录时，我们可能获取您的 TapTap 用户 ID 与昵称，用于登录与账号服务。
  • 实名认证信息：根据国家相关法律法规及游戏防沉迷要求，TapTap 会收集您的实名身份信息以完成实名认证与未成年防沉迷限制。
  • 运行日志：游戏运行过程中产生的错误日志、崩溃信息，用于改进产品稳定性。

三、我们如何使用这些信息

  • 实名认证与防沉迷：完成实名验证，识别未成年人并执行防沉迷时长限制。
  • 广告服务：通过 Unity Ads 向您展示激励视频广告，并按您的选择提供广告奖励。广告 SDK 可能出于投放与统计目的处理设备标识符。
  • 账号登录：提供 TapTap 登录功能，同步游戏进度。
  • 服务改进：分析运行数据以修复问题、优化体验。

四、第三方 SDK 与信息共享

本游戏集成了以下第三方 SDK，它们可能各自处理您的部分信息，其数据处理行为受其隐私政策约束：

  • TapTap SDK（登录/实名/防沉迷）：由易玩（上海）网络科技有限公司运营。用于登录认证、实名认证、防沉迷限制。请参阅 TapTap 隐私政策。
  • Unity Ads（广告服务）：由 Unity Technologies 运营。用于展示激励视频广告。请参阅 Unity 隐私政策。

除上述为提供游戏服务所必需的共享外，我们不会向任何第三方出售或非法共享您的个人信息。

五、信息的存储

您的个人信息将存储于中国大陆境内的服务器。我们将在实现本政策所述目的所需的期限内保留您的信息，法律法规另有规定的除外。

六、您的权利

  • 您可以在首次启动时选择同意或拒绝接收广告及登录服务，拒绝不影响游戏核心功能。
  • 您可以随时在游戏设置中撤回隐私同意，或退出 TapTap 登录。
  • 您有权查询、更正、删除您的个人信息，或注销相关账号。
  • 未成年人应由其监护人陪同阅读本政策，并在监护人同意后使用本游戏。

七、未成年人保护

本游戏适合 8 岁及以上用户。我们将严格执行国家未成年人保护相关规定，通过 TapTap 实名认证与防沉迷系统对未成年人游戏时长、时段进行限制。我们建议监护人对未成年人的游戏行为进行合理引导。

八、政策变更

我们可能适时修订本政策。重大变更时，我们将在游戏内显著位置提示或另行通知。请您定期查阅最新版本。
